# 星落遺跡：叢林篇

踏入被叢林吞沒的古老遺跡，穿越平台、避開尖刺，找回散落各處的星之碎片，開啟神殿出口。這是一款以 Phaser 4 製作的 2D 平台跳躍遊戲。

## 立即遊玩

[開始叢林探險](https://ieason0911.github.io/starfall-jungle-platformer/)

## 遊戲玩法

- 收集全部 **8 枚星之碎片**，解鎖神殿出口。
- 小心遺跡中的尖刺；失去所有生命前抵達出口即可完成試煉。
- 桌機可用鍵盤遊玩，手機和平板提供觸控按鈕。

## 操作方式

| 動作 | 操作 |
| --- | --- |
| 移動 | `←` `→` 或 `A` `D` |
| 跳躍 | `Space`、`↑` 或 `W` |
| 觸控遊玩 | 使用畫面上的方向與跳躍按鈕 |
