# ✦ 星象防詐牌局

**看清情境、選對應對，用一場星象牌局練習防詐直覺。**

荷官每回發出一張情境卡，你要從手牌中選出最安全的做法。遊戲收錄包裹通知、假冒銀行、投資群組、親友借款等常見詐騙情境，並在出牌後說明判斷重點。

## 立即遊玩

前往 [星象防詐牌局 GitHub Pages](https://ieason0911.github.io/star-scam-card-game/) 開始遊戲。第一次進入時，按下「開始試煉」即可抽取第一張情境卡。

## 遊玩教學

### 第一步｜讀懂情境卡

每回合先看荷官發出的情境卡。卡片會描述一段你可能遇到的訊息、電話或交易，留意對方要求你做什麼，以及有沒有催促、保證獲利、索取驗證碼或要求轉帳等警訊。

### 第二步｜從手牌選一張

畫面下方會發出五張應對卡。選出最能保護自己金錢與個人資料的做法，再點擊卡片出牌。每題只能選一張；不確定時，優先使用官方管道查證，或先停下來不要操作。

### 第三步｜閱讀出牌回饋

出牌後，遊戲會顯示得分與這題的防詐說明。看完解說，再按下「收回手牌・進入下一題」，繼續接受考驗。重新開始時，情境順序與手牌順序都會重新排列。

## 計分與通關

選到正確應對卡可獲得 **6 分**；選到較無關的做法得 **0 分**；選到錯誤做法扣 **2 分**。分數最低為 0 分，不會因答錯而變成負分。

累積到 **30 分**時，遊戲立即結束並顯示「恭喜你通過考驗」。最多可答 11 題；答完第 11 題仍未達 30 分時，會顯示「再接再厲，防範詐騙你我他」。

## 防詐判斷小提醒

遇到要求匯款、提供簡訊驗證碼、安裝陌生 App 或點擊不明連結的情況，先暫停操作。請自行查找機構的官方電話或網站，不要使用對方訊息裡附上的連結與聯絡方式來驗證身分。

## 關於本遊戲

本遊戲以 Phaser.js 製作，使用色塊卡面、星盤與星點營造占星牌桌氛圍。開啟遊戲需要網路連線，因為 Phaser.js 由 CDN 載入。
